##  Full-Stack E-Commerce Platform

A feature-rich, fully-functional e-commerce web application built with React, Node.js, Express, and MongoDB.

###  Key Features

* ** Complete Authentication & Authorization:**
  * Secure User Registration & Login (Email/Gmail).
  * Password Reset System via Email Verification Code.
  * Protected Routes & User Profile Management (Update Profile & Password).

* ** Shopping & Cart Management:**
  * Interactive Product Selection (Select product color & custom quantities).
  * Dynamic Shopping Cart (Add/Remove items, view real-time price updates).
  * **Coupon & Discount System:** Apply discount codes with instant price calculations (Price before/after discount).

* ** Flexible Checkout & Payments:**
  * **Cash on Delivery (COD):** Integrated order placement with home address selection.
  * **Online Payment:** Integrated Card/Visa processing.

* ** Personal User Dashboard:**
  * **Order Tracking:** Detailed order history & status management.
  * **Wishlist:** Quick-add favorite items directly synced to user profile.
  * **Address Book:** Manage delivery addresses for seamless checkout.

* ** Catalog & Navigation:**
  * Dynamic filtering by Brands & Categories.
  * Dynamic Pagination across Products, Brands, Categories, and Orders.
 
  * to visit : https://front-end-ecommerce-i9zd.vercel.app/

* **🔔 Interactive UX/UI:**
  * Live **Toast Notifications** for errors, validation warnings, and success actions.
  * Responsive Design with Skeleton Loader / Loading States.
